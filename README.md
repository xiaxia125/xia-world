# XIA HOME

**一个可以走进去的前端职业主页。**

**在线地址：[xia-world.vercel.app](https://xia-world.vercel.app)** —— 打开即玩，无需安装。

夏夏 / 前端开发工程师 / 5 年经验。这里不是一张往下滚的简历，而是一座可以第一人称漫游的方块小岛：广场、项目展厅、工作室、球场、池塘和天台都在同一个空间里；需要快速了解职业信息时，也可以随时打开公开职业档案。

公开入口只有一个：**职业档案**。开始页、HUD、`P` 快捷键和出生点旁的档案屏都会打开同一份档案。

> A walkable professional profile.
>
> 已部署在 Vercel：<https://xia-world.vercel.app>

## 功能清单

### 3D 世界

- 第一人称漫游：鼠标控制视角，`WASD` / 方向键移动，`Shift` 奔跑，`Space` 跳跃
- 方块地形与建筑：AABB 碰撞、楼梯自动踏步、重力、最高地面吸附、跳跃缓冲和 coyote time
- 90 Hz 固定物理子步 + 仅摄像机做台阶平滑，减少行走时的抖动和位置漂移
- 广场与喷泉、项目展厅、工作室、书架密室、篮球场、池塘、树林和天台
- 出生点右侧的公开职业档案屏，走近按 `E` 即可阅读
- 由旧健身房改造的项目展厅：三块大型项目屏，展示代表项目、职责和技术栈
- 工作室电脑、三张方向海报、书架、街机、影院、望远镜、天气电台、鸭子和隐藏留言
- 12 分钟一轮昼夜循环，太阳、月亮、天空渐变、夜间灯光
- 晴 / 雨 / 雪 / 雾四种天气，雨雪粒子、湿地反光、环境音变化
- 高 / 低画质切换；移动端默认低画质，限制像素比、关闭阴影
- 开始页、加载进度、准星、交互提示、HUD、设置面板和暂停恢复
- `localStorage` 自动保存位置、视角、时间、天气、画质、灵敏度、音量、音乐开关和彩蛋进度
- WebGL 不可用时显示说明和公开邮箱，不把不可用的 3D 世界伪装成正常页面

### 公开职业档案

- 开始页「先看职业档案」、HUD「CV 职业档案」、`P` 快捷键、出生点档案屏共用同一个面板
- 五个章节：概览、项目、经历、技能、联系
- 内容全部来自 `src/profile.ts`，3D 档案和世界内项目屏共享同一份数据
- 项目卡展示职责、技术栈和结果，省略客户方敏感项目名
- 经历包含公司、岗位、时间与工作内容；教育背景单独展示
- 邮箱按需复制或打开邮件客户端；不展示手机号和其他私人信息
- 键盘焦点管理、`Esc` / 「返回世界」关闭、移动端整页滚动和粘性章节导航

### 2D 覆盖层

- 街机和天台影院通过 iframe 覆盖层运行
- 打开 / 关闭覆盖层时保留 3D 世界状态
- `Esc` 或「返回世界」关闭覆盖层

## 内容与隐私

公开资料来自个人简历，经过筛选整理；源文件不会复制进项目，也不会随站点发布。

会公开：

- 姓名、求职方向、5 年前端开发经验
- 公司名称、岗位、任职时间和公开的工作内容
- 项目方向、职责、技术栈和可公开的结果
- 教育背景
- 工作邮箱

不会公开：

- 手机号
- 年龄、性别、政治面貌、身份证等私人信息
- 客户方敏感项目名
- 完整源简历下载

邮箱没有直接写进静态 HTML，而是由 `src/profile.ts` 中的两段常量在运行时拼装。这个处理只能降低简单抓取的概率，不能阻止刻意抓取；如果未来需要更强的隐私保护，应改成服务端联系方式或表单。

需要修改公开内容时，只改 `src/profile.ts`。职业档案和 3D 世界里的档案屏、项目展厅会一起更新。

## 技术栈

| 层 | 选型 | 用途 |
| --- | --- | --- |
| 3D 渲染 | Three.js + WebGL2 | 方块世界、实例化方块、灯光、雾、阴影 |
| 语言 / 构建 | TypeScript + Vite | 类型检查、开发服务器、静态构建 |
| 物理 / 碰撞 | 自研 AABB + 固定子步 | 移动、跳跃、楼梯踏步、最高地面吸附 |
| HUD / 档案面板 | React + CSS | 界面状态、职业档案和响应式布局 |
| 世界内屏幕 | `CanvasTexture` | 动态显示项目、档案入口等，避免实时 iframe 纹理 |
| 音频 | Web Audio API | 程序化音乐、环境音、天气音和交互音效 |
| 存档 | `localStorage` | 世界状态、设置、彩蛋、街机最高分 |
| 外部视频 | `media.w3.org` | Sintel 预告片；离线时仍可看内置短片 |

### 几个实现细节

- 物理以 `1/90s` 固定步长推进，渲染帧率变化不会改变移动速度
- 上台阶段只平滑摄像机高度，角色碰撞体保持在真实地面高度，避免视觉漂移变成物理漂移
- 落地检测选最高可站立碰撞面，楼梯和天台边缘不会来回吸附
- 摄像机使用对数深度缓冲和较远的远裁面，减少远处方块闪烁
- 方块场景使用 `InstancedMesh` 合并同材质方块；天空、标识、屏幕使用程序化 Canvas 纹理
- 职业档案用 `src/profile.ts` 做唯一数据源，避免 3D 和 UI 内容漂移
- 移动端根据 `(pointer: coarse)` 启用摇杆和触摸视角，默认低画质

## 运行与部署

### 环境要求

- Node.js `^20.19.0` 或 `>=22.12.0`（Vite 8 的要求）
- npm 10+

### 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。

### 构建

```bash
npm run build
npm run preview
```

`npm run build` 会先执行 `tsc --noEmit`，再把静态产物输出到 `dist/`。构建会生成 3D 世界和 `public/pages` 下的街机 / 影院页面。

### 部署

这是纯静态站点，没有后端。

**Vercel**

线上地址：<https://xia-world.vercel.app>

重新部署或换一个 Vercel 项目时：

1. 导入仓库
2. Framework Preset 选择 Vite
3. Build Command：`npm run build`
4. Output Directory：`dist`
5. 绑定域名并开启 HTTPS

**Cloudflare Pages**

- Build command：`npm run build`
- Build output directory：`dist`
- 建议开启 Brotli / 自动资源压缩

**GitHub Pages**

`vite.config.ts` 中的 `base` 是 `"./"`，因此 `dist/` 可以直接部署到用户名仓库或项目子路径。把 `dist/` 内容发布到 Pages 即可；页面使用锚点导航，不需要 SPA 重写。

**上线前建议**

- 确认 `dist/pages/*.html` 已一起上传
- 如果使用 CSP，允许 `media.w3.org`（Sintel 预告片）和 `data:` 图标
- 在手机竖屏、横屏各走一遍；影院和街机也测试 iframe 内布局
- 用 `npm run build` 确认类型检查和构建通过

## 上线前检查

- 在支持 WebGL 的桌面浏览器中检查漫游、档案屏和项目展厅交互
- 确认开始页、HUD、`P` 快捷键和档案屏都打开同一份职业档案
- 在职业档案内切换五个章节，测试 `Esc` 和「返回世界」
- 在手机浏览器中检查触控移动、`CV` 按钮、档案面板滚动和粘性章节导航
- 确认公开页面没有手机号、年龄、性别、政治面貌
- 街机、影院与 iframe 返回流程均正常
- 执行 `npm run build` 并部署新的 `dist/`

## 已知限制

- 桌面端使用 Pointer Lock；按 `Esc` 释放鼠标是浏览器行为，不是页面 bug
- 背景音乐和短片声音需要一次用户点击后才能启动，这是浏览器自动播放策略
- Sintel 预告片来自外部网络；网络不可用时会显示内置短片入口
- 移动端竖屏时街机 / 影院画面受 16:9 比例限制，横屏体验更好
- 打包后 `engine` chunk 仍超过 500 kB；不影响功能，后续可继续拆分 Three.js 和交互逻辑
- 这是单人静态站点，没有账号、后端数据库或多人同步
